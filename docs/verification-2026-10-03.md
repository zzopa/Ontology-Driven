## 实测性能

启动采集和编译约 0.4—0.6 秒。最近真实模型联调：员工概况约 16.7 秒，其中 SQL 0.25 秒、回答模型约 9.3 秒；资金全量分组合计 SQL 约 3 秒。模型网络延迟会波动，这些不是响应时间保证。重复问题可复用版本化解析计划，但业务数据仍实时读取。

流式接口持续输出阶段进度；事实校验后的答案逐段发送，不承诺模型生成时逐 token 立即展示。

## 修复与数据发现

- 信科简称转企业代码后，模型曾追加 enterprise_name=信科公司，导致零命中。现已去除冲突的简称名称条件，实库该问题返回 1 条主档，相关事实可追溯。
- 模型曾把统计目标填成 id 字段。已固定确定性的统计粒度，规范空分组并补回归。
- 会议 fields_json 在实库是存有 JSON 的文本；聚合、筛选和按月分组均做 JSON 解析兼容，使用会议开始时间，而不是 created_at。
- 薪酬历史金额含非数字字符串，本次只确认非数字，未证明具体加密算法。全期间工资合计被明确拒绝；有合法数值的月份可单独查询。不得擅自转 0、猜数或漏算后宣称完整合计。
- 抽样 51 条关系，每条最多 100 个非空键：合同→企业台账发现 95 个源样本匹配多个台账目标；这是跨月记录粒度风险，不解释成多个企业。合同→国资业务数据的一条探测达到 2 秒超时，明确标记检查未完成。其余样本未发现多目标不等于全量唯一或业务正确。

关系检查保存在 data/runtime/relation_validation.json；管理页可重新生成。已有配置关系未因抽样结果被自动审核或删除。

## 安全与限制

服务已监听 0.0.0.0:8088，当前电脑 IPv4 为 192.168.31.242，配置允许网段 192.168.31.0/24。验证了本机和当前网卡地址的访问；其他机器是否受防火墙影响仍需从其他设备实际访问确认。

本机管理可写，局域网管理只读；问答尚无账号/行列授权。当前不能直接暴露公网。新增业务基础目录自动发现，准确的业务口径仍需要补充配置和验收。

事实编号、数字原子和金额单位检查不能证明整句语义完全正确。排名、复杂指标公式、自动补充查询、多人审核工作流和全量关系唯一性分析仍未实现，详见实施说明。当前测试样例通过率不能当成任意自然语言问题的准确率。
