# 工作台 UI 与嵌入验收

本次将前端迁移到 Next.js App Router、Tailwind CSS、Lucide React 和 Framer Motion，生产静态构建由 FastAPI 8088 同源提供。现有业务本体、数据库查询和模型回答链路保留。

## 已验证

| 检查 | 结果 |
| --- | --- |
| TypeScript 严格检查 | `npm run typecheck` 通过 |
| Next.js 生产构建 | `/`、`/ontology`、`/embed` 静态导出成功 |
| 前端逻辑测试 | 5 / 5：表单组句、可选条件、NDJSON 分片及末尾无换行、嵌套值、宿主来源白名单 |
| Python 测试 | 41 / 41，包含 9 项本地 PostgreSQL TEMP 集成测试，无跳过 |
| HTTP 页面 | 三个入口均返回 200，静态 JS/CSS 正常加载 |
| 真实员工问答 | 表单生成“信科 员工 李康平 查询详细信息”，观察到阶段进度，成功显示回答、解析条件和来源依据 |
| 全部字段明细 | 命中数按钮打开完整记录；空值、中文字段和长值可查看 |
| 关联分页 | 70 条津贴记录，第二页显示 21–40 条；20 行正常加载 |
| 统计分页 | 资产卡片 23,007 条；独立只读 `SELECT COUNT(*) FROM public.asset_card_record` 得到同一结果；第二页 20 行、84 个允许展示字段 |
| 图谱与 SQL | 员工查询显示 7 表 / 6 关系；实际 SQL、独立参数及证据覆盖正常 |
| 嵌套弹层 | Escape 仅关闭最上层，焦点返回对应单元格；再次 Escape 关闭明细 |
| 管理表单 | 对象名称和字段中文名称写入草稿，保留原指标及 `company_name` 等未编辑绑定；重新加载弹出未保存确认 |
| 管理权限 | 本机可编辑；当前 LAN 地址 `192.168.31.242` 的 `/api/ontology` 返回 `can_edit=false` |
| 弹窗布局 | 1000×780 的 `/embed` 初始页面完整展示，无横向或纵向溢出；不展示侧栏 |
| 小屏布局 | 390×844 下单列；实际内容宽度等于视口宽度，无横向溢出 |
| 浏览器日志 | 验证期间未观察到警告或错误 |

测试仅临时改动前端草稿，随后丢弃，没有保存业务规则；本体 revision 仍为 `1d7cf0609eed…`。未修改业务数据。嵌入宿主白名单默认为空，没有擅自为其他网站开放嵌入权限。

截图：[弹窗版](../artifacts/verification/workspace-embed.jpg)、[小屏版](../artifacts/verification/workspace-mobile.jpg)。使用与安全接入见 [前端与嵌入说明](frontend-and-embedding.md)。
